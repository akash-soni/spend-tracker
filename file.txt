❯ What this project is for?                                                     

  Read 2 files (ctrl+o to expand)

● This is a step-by-step tutorial project for building a personal expense/spend
  tracker web app using Flask and SQLite.

  It's a starter skeleton where students implement features incrementally:

  - Step 1 — Database setup (SQLite with get_db, init_db, seed_db)
  - Step 3 — User logout
  - Step 4 — User profile page
  - Step 7 — Add an expense
  - Step 8 — Edit an expense
  - Step 9 — Delete an expense

  The scaffolding already includes:
  - Landing, login, and register pages (templates + routes)
  - CSS styling and JS
  - Placeholder routes for features students will build

❯ What is the tech stack used for this project?                                 

● Based on the code and files:

  - Backend: Python + Flask (web framework)
  - Database: SQLite (via Python's built-in sqlite3)
  - Frontend: HTML (Jinja2 templates), CSS, JavaScript
  - Testing: pytest + pytest-flask
  - Server: Flask dev server (port 5001)

  No external database server, ORM, or frontend framework — intentionally kept
  simple for a tutorial project.
